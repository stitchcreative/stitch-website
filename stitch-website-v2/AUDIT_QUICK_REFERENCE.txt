DESIGN TOKENS
───────────────────────────────────────────────────────────────────────────────
--max-w:    1280px
--pad-x:    clamp(20px, 5vw, 80px)
            = 80px max on desktop

Standard .container CSS:
  max-width: var(--max-w);           /* 1280px */
  margin: 0 auto;
  padding: 0 var(--pad-x);           /* Horizontal padding only */

Expected content width: 1120px (desktop)


THE PROBLEM
───────────────────────────────────────────────────────────────────────────────
.container has CSS:            padding: 0 var(--pad-x)
Some instances have inline:    style="padding:80px var(--pad-x)"

Result: Double horizontal padding (var(--pad-x) × 2 = 160px per side)
Content width becomes: 960px instead of 1120px
